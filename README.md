# prvithi transcripts

A read-only viewer for a curated sample of 500 customer conversation histories.

- 400 agentic histories: recorded CSAT average 4.28.
- 100 human histories: recorded CSAT average 3.90.
- 400 ratings of 4-5, 75 ratings of 3, and 25 ratings of 1-2.
- NPS +57.1, calculated from 49 recorded responses available by the selected CSAT answers.

This sample was selected to meet requested rating targets and is not a random sample or an estimate of overall performance. Message text and stored ratings are unchanged. Customer-facing history is included through each selected CSAT answer; internal tool logs are excluded.

`index.html` is self-contained, including image previews. GitHub Pages serves the root of `main`. No backend or build step is required.
